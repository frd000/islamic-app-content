# Islamic App — content packs

Books for the **Library** of Islamic App (a free Android app: no ads, no tracking).

- `catalog.json` — the list of books the app shows. New books can be added here without a new app version.
- The book files themselves are in this repository's **Releases** (for example `books-v1`).
  Every file in the catalog has its size and SHA-256 checksum; the app checks both after downloading.

## What is here
Only content that is **public domain** or whose publisher allows free re-use (for example the
IslamHouse.com and QuranEnc.com terms: unchanged text, with credit and version). Each book in
`catalog.json` names its author, school (maslak), source link, licence and the exact credit line.
The texts are published exactly as the sources give them — nothing is edited, translated or
summarized.

If you are a rights holder and see a problem, please open an issue in this repository.
